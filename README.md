# Wave 5 — Multi-Card Consent Interrupt Mockup

Interactive, self-contained HTML mockup of the **Wave 5** personalization-consent
interrupt for Outlook, reworked as a **3-card click-through**:

1. **Card 1 — Benefit hook** → *Continue*
2. **Card 2 — How it works + trust** → *Continue*
3. **Card 3 — The ask** → *Not now* (left) / *OK* (right)

Two iterations are included (sourced from the *Consent Experimentation Matrix* “Wave 5” sheet):

- **Iteration 1 — W5.1 “Tailored to you”** (Outlook-scoped)
- **Iteration 2 — W5.4 “Recommendations that follow what you like”** (Microsoft ecosystem-wide)

## Usage

Open `index.html` in any modern browser. Toggle between iterations, click through
the dialog, or use the static storyboard below for screenshots/review.
